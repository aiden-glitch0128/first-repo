# 끝까지

**책 한 권을 끝내기 위한 집필 시스템**

출판 여부보다 "끝까지 완성했다"는 경험을 만드는 데 초점을 둔 개인 집필 앱입니다.

## MVP 원칙

- 매일 사용자가 고민하지 않도록 **오늘 할 일 하나**를 제시한다.
- 글자 수보다 **소재 → 채택 → 초안 → 원고**의 이동을 진행률로 본다.
- 소재만 모으며 회피하지 않도록 일정량 이후에는 채택/초안 작업을 우선한다.
- 연속 집필 일수를 기록한다.
- 모든 데이터는 우선 브라우저 localStorage에 저장하고 JSON 백업을 제공한다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속.

## 현재 범위 (v0.1)

- 책 프로젝트 이름 설정
- 하루 기준 글자 수 설정
- 소재 추가
- 소재 → 채택 → 초안 → 원고 파이프라인
- 초안/원고 직접 편집
- 오늘의 미션 자동 생성
- 일일 완료 및 연속 집필 기록
- JSON 백업
